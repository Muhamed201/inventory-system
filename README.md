# InvenTrack

## Назначение
Приложение для учёта материальных ценностей организации и проведения инвентаризаций:
фиксация объектов учёта, сверка фактического количества с учётным и формирование
результата инвентаризации по каждому объекту.

## Целевая аудитория
Сотрудники организаций, ответственные за учёт материальных ценностей (кладовщики,
материально ответственные лица), и руководители, использующие результаты
инвентаризации для контроля сохранности имущества.

## Предметная область
Учёт и инвентаризация материальных ценностей: сопоставление данных бухгалтерского
учёта с фактическим наличием объектов, выявление излишков и недостач, фиксация
результатов проверок, проводимых сотрудниками.

## Основные сущности
- Объект — материальная ценность, подлежащая учёту (наименование, учётное количество).
- Инвентаризация — мероприятие проверки фактического наличия объектов на определённую дату.
- Сотрудник — материально ответственное лицо, проводящее инвентаризацию.
- Результат — итог сравнения учётного и фактического количества объекта (соответствие,
  излишек, недостача).

## Основные функции
- Расчёт расхождения между учётным и фактическим количеством объекта.
- Определение результата инвентаризации по величине расхождения (соответствие /
  излишек / недостача).
- Определение критичности расхождения по заданному порогу.
- Формирование текстового отчёта по результату инвентаризации объекта.
